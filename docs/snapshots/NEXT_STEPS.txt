📋 下一步：获取 Google API 凭据（需要 3-5 分钟）

请按照以下步骤操作：

┌─────────────────────────────────────────────────────────────┐
│ 步骤 1: 创建 Google Cloud 项目                              │
└─────────────────────────────────────────────────────────────┘

1. 打开浏览器访问：
   👉 https://console.cloud.google.com/

2. 点击顶部的项目下拉菜单

3. 点击"新建项目"

4. 输入项目名称（例如：ZeroClaw Calendar）

5. 点击"创建"并等待项目创建完成


┌─────────────────────────────────────────────────────────────┐
│ 步骤 2: 启用 Calendar API                                   │
└─────────────────────────────────────────────────────────────┘

1. 直接访问：
   👉 https://console.cloud.google.com/apis/library/calendar-json.googleapis.com

2. 确保选择了刚创建的项目

3. 点击蓝色的"启用"按钮

4. 等待 API 启用完成


┌─────────────────────────────────────────────────────────────┐
│ 步骤 3: 配置 OAuth 同意屏幕（首次需要）                     │
└─────────────────────────────────────────────────────────────┘

1. 在左侧菜单选择"OAuth 同意屏幕"

2. 选择"外部"用户类型，点击"创建"

3. 填写以下必填信息：
   • 应用名称：ZeroClaw Calendar
   • 用户支持电子邮件：（您的邮箱）
   • 开发者联系信息：（您的邮箱）

4. 点击"保存并继续"

5. "范围"页面直接点击"保存并继续"（跳过）

6. "测试用户"页面：
   • 点击"+ ADD USERS"
   • 添加您的 Google 账号邮箱
   • 点击"保存并继续"

7. 点击"返回到信息中心"


┌─────────────────────────────────────────────────────────────┐
│ 步骤 4: 创建 OAuth 客户端 ID                                │
└─────────────────────────────────────────────────────────────┘

1. 在左侧菜单选择"凭据"

2. 点击顶部"+ 创建凭据"

3. 选择"OAuth 客户端 ID"

4. 应用类型选择：**桌面应用**
   （重要：必须选择桌面应用，不是 Web 应用）

5. 名称输入：ZeroClaw Calendar Client

6. 点击"创建"


┌─────────────────────────────────────────────────────────────┐
│ 步骤 5: 下载凭据文件                                        │
└─────────────────────────────────────────────────────────────┘

1. 创建成功后会显示客户端 ID 和密钥

2. 点击"下载 JSON"按钮（或关闭弹窗后点击下载图标 ⬇️）

3. 将下载的文件重命名并移动到：
   ~/.mcp-servers/google-calendar-credentials.json

   可以在终端运行：
   
   mv ~/Downloads/client_secret_*.json ~/.mcp-servers/google-calendar-credentials.json
