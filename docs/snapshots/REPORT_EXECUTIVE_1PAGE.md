# ZeroClaw 一頁式專案摘要（管理層）

日期：2026-05-11

## 專案是什麼

ZeroClaw 是一個以 Rust 打造的 AI 代理執行平台，主打小資源、可替換、可部署、可治理。它不是單一聊天機器人，而是可支撐多模型、多通道、多工具的「代理作業底座」。

## 商業/運營價值

- 降低基礎設施成本：適合低規格主機與邊緣設備。
- 降低供應商鎖定：模型與通道可替換。
- 降低運維摩擦：已具容器化、反向代理、TLS、systemd 部署路徑。
- 降低擴充成本：模組化架構有利於新增整合能力。

## 目前成熟度（本次盤點）

- 原始碼與文件規模成熟（src 214 檔、docs 146 檔）
- 具備標準品質門檻（fmt/clippy/test/CI）
- 有規格驅動流程（openspec）
- 已建立 VPS/Hetzner 自動化部署規格與資產

## 主要風險

1. 高變更期的回歸風險（目前工作樹變更量大）
2. 多 feature 組合造成測試矩陣膨脹
3. 對外服務鏈路（Gateway/TLS/Nginx）帶來營運可用性與安全壓力

## 接下來 30 天建議

1. 以 security + gateway + deploy 建立強制 smoke pipeline。
2. 對常用 feature 組合建立最小覆蓋矩陣。
3. 將高風險變更拆成主題化 PR，加入回退策略。
4. 補齊規格文件中的 TBD 目的敘述，提升治理可追溯性。

## 決策建議

建議持續投資本專案。ZeroClaw 的架構方向正確、可擴展性佳，短期重點應放在穩定交付能力（測試與發佈治理）而非大幅重構。
